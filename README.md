# dotenorio.com

Cartão de visitas de Fernando Migliorini Tenório: uma página estática, sem build e sem dependências, publicada na Vercel.

Os atalhos `/sites`, `/pdi`, `/linkedin`, `/github`, `/facebook` e `/steam` são redirecionamentos definidos em `vercel.json`. O `/pdi` abre o "fazer uma cópia" do PDI de 1 página da palestra de carreira (Google Docs, precisa estar compartilhado como "qualquer pessoa com o link").

Visitas: Vercel Web Analytics (script no fim do `index.html`). Para contar, ligue em **Analytics → Enable** no projeto `dotenoriocom` da Vercel. Os atalhos de `vercel.json` são redirecionamentos e não entram na contagem.
